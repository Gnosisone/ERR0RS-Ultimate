## Architecture notes

- Mission state: ~/.err0rs/mission_state.json, server-authoritative.
  advance_mission clears active_mission + sets just_completed (one-shot)
  on completion. /api/mission/clear-celebration clears the flag after FE
  renders the celebration.
- Ethics gate: per-launcher-PID. session_ethics_ack.json stores
  launcher_pid; mismatch = re-fire. Pi reboot or relaunch invalidates.
- Operator profile: get_full_profile() joins profile.json, progression.json,
  preferences.json, mission_state, lesson_state in one call.
- XP awards now fire in operator._run_tool (was bypassed). Kill chain still
  bypasses (item 1 above).

## DC workflow reminders (from prior sessions)

- write_file rewrite-then-append chunking (≤30 lines) for large files
- edit_block needs exact match; Unicode chars cause silent failures
- Verify syntax: python3 -c "import ast; ast.parse(...)" / node --check
- Background launcher: nohup ... > log 2>&1 & disown (NOT shell & alone)
- The chained "kill && restart" in one command often loses the restart —
  run the nohup launcher start as its own separate command.
